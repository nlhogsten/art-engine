# Video Brief Template

Use for **every new visual idea** before any render. Fill it in, get sign-off, then build. One page.

## Goal
What is this shot/sequence supposed to do in the episode? (One or two sentences.)

## Look references
Links or paths to refs. If Nate named a ref ("old Evan Mock look"), fetch it into the media library and link it here.

## Beats
Each beat: **one sentence describing the end-state** (what the final frame looks like) + the styleframe path once rendered.

| # | End-state (one sentence) | Styleframe |
|---|--------------------------|------------|
| 1 | | |
| 2 | | |

## Motion description
How it moves between the end-states. Name the dictionary moves (video-dictionary/DICTIONARY.md): the move, the subject, the duration. Keep it to what the keyframe system can actually do — per-frame interpolation, eased.

## Assets needed
List every asset with its source. Generated assets go through the asset gate (checkerboard-verified transparency) before entering any composition.

## AMBIGUITIES
**Hard rule: this section must be empty or explicitly user-confirmed before ANY render. Resolving ambiguity by guessing is a bug — write that down, don't work around it.**

If a direction has two legitimate readings, list them here and wait:
- Reading A: …
- Reading B: …
- User picked: … (date)

No entry may be silently resolved by the builder. An empty section means "no known ambiguities."

## Sign-off
- [ ] Styleframes approved (look)
- [ ] Motion description approved
- [ ] Ambiguities resolved
- [ ] Render authorized
